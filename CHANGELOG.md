### Added
- Milestone 5C.2 Distributable Apple SDK & XCFramework Packaging (`scripts/apple/`): One-command multi-target Apple XCFramework build script (`build-xcframework.sh`), mandatory 5 Apple static architecture targets (`aarch64-apple-darwin`, `x86_64-apple-darwin`, `aarch64-apple-ios`, `aarch64-apple-ios-sim`, `x86_64-apple-ios`), thin-slice deployment target & symbol verifier (`verify-xcframework.sh`, `required_symbols.txt`), release zip archive & checksum generator (`create-release-archive.sh`, `release-manifest.json`), distribution package generator (`generate-release-package.sh`, `dist/swift-package/Package.swift`), C module import abstraction (`NativeModule.swift` with `#if canImport`), plain C / C module / macOS consumer integration test suite (`test-consumers.sh`), Xcode iOS application & unit test host project (`integration/apple/ios-consumer/KurmanciConsumer.xcodeproj`), builder-generated test fixture (`integration/apple/fixtures/apple_consumer_test.bin`), `XCLocalSwiftPackageReference` resolution, isolated Rust-free GitHub Actions CI jobs (`ci.yml`), and remote `kurmanci-swift` package publication & resolution release automation (`release-apple-sdk.yml`).
- Milestone 5C.1 Repository-Local Swift Wrapper Foundation (`swift/`): Idiomatic Swift Package (`KurmanciEngine`), `CKurmanci` Clang target, ABI version verification (v1.0), file and `Data` initialization, typed Swift errors (`KurmanciError`), Swift-owned DTOs (`PackInfo`, `Suggestion`, `Prediction`), negative limit validation, safe context array slicing (`Array(context.suffix(2))`), `@unchecked Sendable` thread safety, embedded NUL byte validation, non-file URL rejection, bundled prediction test fixture (`prediction_test.bin`), `defer` handle destruction, `swift test` suite (`KurmanciEngineTests.swift`), release build CI step, and command-line example (`KurmanciExample`). Updated C ABI header constant notation (`0U`, `1U`, etc.) for seamless Swift Clang importer mapping without altering numeric values or binary ABI layout.
- Milestone 5B Stable C ABI & FFI Bindings (`kurmanci-ffi`): Panic-safe C99/C++11 integration interface (`ffi/include/kurmanci.h`), fixed-width integers (`typedef uint32_t kmr_status`), ABI versioning (`1.0`), named domain constants (`kmr_suggestion_kind`, `kmr_prediction_source`), explicit string lifetime contracts, deterministic out-parameter initialization, panic containment (`catch_unwind`), C smoke test (`c_smoke_test.c`), C/C++ header inclusion checks (`include_c.c`, `include_cpp.cpp`), and Rust FFI unit test suite (`abi_test.rs`).
- Milestone 5A Integration-Ready Engine API: Established high-level, thread-safe, immutable public Rust API (`KurmanciEngine`), compact typed error handling (`EngineError` & `PackLoadError`), `PackInfo` metadata extracted from pack header, options structs (`SuggestOptions`, `CorrectionOptions`, `CompletionOptions`, `PredictionOptions`), consolidated DTOs (`SuggestionResult`, `Prediction`), infallible query returns (`is_known_word`, `correct`, `complete`, `suggest`, `predict_next`), result limit clamping (max 50), CLI migration, integration test suite (`public_api_test.rs`), Criterion benchmarks (`engine_benchmarks.rs`), and path-driven embedding example (`embed_example.rs`).
- Milestone 4C.3 Reviewed-Pack Rebuild & Re-evaluation: Rebuilt `reviewed` language pack incorporating 13 authoritative human lexical review decisions, increasing entry count to 35 (33 seed + 2 approved external entries `şeq`, `şer`). Documented `sê` conflict-group non-selection, observed `şe` prefix-completion benchmark ranking regression, and 2-pass determinism verifications in `docs/evaluation/4c3-reviewed-pack-reassessment.md` and `scripts/verify_4c3_reviewed_pack.py`.
- Initial Rust core language engine (`kurmanci-engine`) with Trie prefix autocomplete, weighted Damerau-Levenshtein edit distance, and diacritic-sensitive scoring (`i ↔ î`, `u ↔ û`, `s ↔ ş`, `c ↔ ç`, `e ↔ ê`).
- Reproducible binary data-builder compiler (`kurmanci-data-builder`) generating serialized `.bin` language packs and release manifests.
- Command-line interface (`kurmanci` binary) supporting `suggest`, `complete`, `correct`, `contains`, and `benchmark` commands.
- Canonical handcrafted Kurmancî seed lexicon (`data/reviewed/lexicon.jsonl`, 32 entries) and typo dataset (`data/errors/typos.json`).
- Registered, acquired, and preserved first real Kurmancî Hunspell lexical source (`kurdish-hunspell-kmr`, CC BY-SA 4.0, commit `88131d6878ef7fa3ee114aa554adc385ff85b44c`) byte-for-byte in `data/original/kurdish-hunspell-kmr/` with `PROVENANCE.toml` records, license attribution, deterministic acquisition (`data-builder acquire-source`), and automated source integrity verification (`data-builder verify-sources`).
- Deterministic Hunspell `.dic` importer (`data-builder import-hunspell kurdish-hunspell-kmr`) generating provenanced lexicon JSONL (`data/imported/kurdish-hunspell-kmr/lexicon.jsonl`), import summary, rejection log, conflict report, and evaluation benchmark tool (`data-builder evaluate-lexicon`). - Deterministic lexical data quality audit (`data-builder audit-lexicon kurdish-hunspell-kmr`) producing 15 analysis reports under `data/reports/kurdish-hunspell-kmr/quality-audit/`, including cross-checked importer replay, Unicode character inventory, script classification, shape analysis, length distribution, flag/morphology frequency, grouped conflict schema with full morphology evidence, rejection review, suspicious entry detection, manual-seed overlap comparison, benchmark readiness assessment, and stratified review sample.
