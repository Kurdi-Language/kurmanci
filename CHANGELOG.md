## [Unreleased]

### Added
- Initial Rust core language engine (`kurmanci-engine`) with Trie prefix autocomplete, weighted Damerau-Levenshtein edit distance, and diacritic-sensitive scoring (`i ↔ î`, `u ↔ û`, `s ↔ ş`, `c ↔ ç`, `e ↔ ê`).
- Reproducible binary data-builder compiler (`kurmanci-data-builder`) generating serialized `.bin` language packs and release manifests.
- Command-line interface (`kurmanci` binary) supporting `suggest`, `complete`, `correct`, `contains`, and `benchmark` commands.
- Canonical handcrafted Kurmancî seed lexicon (`data/reviewed/lexicon.jsonl`, 32 entries) and typo dataset (`data/errors/typos.json`).
- Registered, acquired, and preserved first real Kurmancî Hunspell lexical source (`kurdish-hunspell-kmr`, CC BY-SA 4.0, commit `88131d6878ef7fa3ee114aa554adc385ff85b44c`) byte-for-byte in `data/original/kurdish-hunspell-kmr/` with `PROVENANCE.toml` records, license attribution, deterministic acquisition (`data-builder acquire-source`), and automated source integrity verification (`data-builder verify-sources`).
- Deterministic Hunspell `.dic` importer (`data-builder import-hunspell kurdish-hunspell-kmr`) generating provenanced lexicon JSONL (`data/imported/kurdish-hunspell-kmr/lexicon.jsonl`), import summary, rejection log, conflict report, and evaluation benchmark tool (`data-builder evaluate-lexicon`). (`.aff` affix expansion remains planned).
- Deterministic lexical data quality audit (`data-builder audit-lexicon kurdish-hunspell-kmr`) producing 15 analysis reports under `data/reports/kurdish-hunspell-kmr/quality-audit/`, including cross-checked importer replay, Unicode character inventory, script classification, shape analysis, length distribution, flag/morphology frequency, grouped conflict schema with full morphology evidence, rejection review, suspicious entry detection, manual-seed overlap comparison, benchmark readiness assessment, and stratified review sample. Verdict: A — suitable for controlled evaluation only.
- Deterministic corpus frequency pipeline (`data-builder import-corpus` & `data-builder build-frequencies`) with corpus registry (`data/source-registry/corpora.toml`), NFC lowercase diacritic-preserving tokenizer, JSONL frequency table (`data/build/frequencies.jsonl`), statistical reports suite (`data/reports/frequencies/`), SHA-256 artifact manifest, and 2-pass byte-for-byte determinism verification in CI.
- Frequency-aware candidate suggestion ranking (Milestone 2E) with binary pack format v2 (`PACK_VERSION = 2`), fixed-point Zipf (`zipf_milli`), deterministic candidate lexicographical comparison (edit cost -> diacritic match -> frequency -> document count -> lexical tie-breaker), `--explain` CLI diagnostic flag, reviewed evaluation dataset (`evaluation/spelling/cases.jsonl`), ranking evaluation tool (`data-builder evaluate-ranking`), and automated evaluation report suite (`data/reports/ranking-evaluation/`).
- Deterministic Bigram Language Model & Next-Word Prediction (Milestone 3A) with sentence boundary isolation (`.`, `!`, `?`, `…`, `۔`), original-context checked u128 integer probability (`probability_millionths`), configurable pruning (`minimum_count = 2`, `maximum_predictions_per_context = 16`), statistical report suite (`data/reports/ngrams/`), binary pack format v3 (`PACK_VERSION = 3`) with lexicon indices (`u32 LE`) and zero duplicate strings, Engine `predict_next` API, CLI `predict-next` command, reviewed benchmark dataset (`evaluation/next-word/cases.jsonl`), evaluation subcommand (`evaluate-next-word`), formal binary pack specification (`docs/BINARY_PACK_SPEC.md`), and 2-pass byte-for-byte CI determinism checks.
- Deterministic Trigrams & Backoff Prediction (Milestone 3B) with sentence-isolated ordered triple extraction `(prev2, prev1) -> next`, checked u128 fixed-point integer probabilities (`PROBABILITY_SCALE = 1_000_000`), configurable bigram/trigram pruning (`data-builder/config/ngrams.toml`), analytical OOV exclusion reporting (`data/reports/trigrams/`), binary pack format v4 (`PACK_VERSION = 4`) appending Trigram Section with lexicon indices (`u32 LE`), `kurmanci_engine::format` shared format constants, strict hard backoff engine API (`predict_next_with_context`), CLI two-word context support (`predict-next ez baş --explain`), reviewed evaluation dataset (`evaluation/next-word/trigram-cases.jsonl`), context prediction evaluation tool (`evaluate-next-word`), dynamic bigram-only baseline comparison, and 2-pass CI determinism verification.
- Corpus Infrastructure & Deterministic Partitioning (Milestone 3C1) with format-sensitive source registry validation (`one-document-per-line` vs `jsonl`), cross-platform normalized document IDs (`<rel_path>:<line>`), canonical JSONL document schema (`data/imported-canonical/<corpus-id>/documents.jsonl`), atomic transaction importer (`import-all-corpora`) with lock file and sibling staging (`data/imported-canonical.tmp_stage/`), canonical import manifest (`data/imported-canonical/manifest.json`), corpus inventory subcommand (`inventory-corpora`), language and script validation + deduplication subcommand (`audit-corpora`), and leakage-free, order-independent train/dev/eval document partitioning (`partition-corpora`).
- Controlled Lexicon Review Infrastructure (Milestone 4A.1) with length-prefixed u64 SHA-256 canonical entry/group identity, immutable `source_revision` hashing, explicit decision target uniqueness (`target_type`, `target_id`), rule-driven review queue generator (`generate-review-queues`, `review-queue-v1`), decision store validator (`validate-review-decisions`, `review-decision-v1`), merged audit report suite (`controlled-review-report-v1`), atomic staged directory replacement, and 2-pass CI determinism verification.
- Controlled Pack Policy & Pack Builds (Milestone 4A.2) with authoritative policy loader (`pack-policy-v1`), three distinct language pack profiles (`seed`, `reviewed`, `experimental-full`), `model_profile = "none"` statistical model exclusion, source-derived licensing attributions (`Apache-2.0` and `CC-BY-SA-4.0`), collision resolution precedence, `collision-report.jsonl` generation, global build lock `data/pack-builds.lock`, atomic staged directory transactions, and `kurmanci-engine` binary loading verification.
- Evaluation Benchmark Schema & Validation Workflow (Milestone 4B.1) with modular `data-builder/src/evaluation/` structure, typed benchmark schemas (`BenchmarkTask`, `BenchmarkCategory`, `BenchmarkReviewStatus`, `BenchmarkSourceInfo`, `BenchmarkExpectation`), length-prefixed domain-separated SHA-256 canonical identity (`case_id`), contradiction & duplicate detection (`validator.rs`), computed provenance overlap reporting (`data/reports/evaluation-provenance/`), draft vs human-reviewed validation rules, and CLI command `validate-eval-cases`.
- Deterministic Three-Pack Comparison Engine (Milestone 4B.2) with CLI subcommand `evaluate-packs`, strict pack validation (`seed`, `reviewed`, `experimental-full`), engine query execution (`AcceptWord`, `CorrectWord`, `CompletePrefix`), task-specific metric calculation (known-word coverage, false-acceptance rate, Top-1/3/5, MRR, completion recall, exact preservation, no-candidate rate, binary size), pairwise improvement/regression classification, deterministic report suite (`data/reports/pack-comparison/`), global build lock `data/pack-comparison.lock`, atomic sibling staging, and 2-pass byte-for-byte determinism verification.
- Benchmark Review Governance (Milestone 4B.3A) with segmented reviewer-ID and exact Gregorian review-date validation, metadata-only draft promotion policy, filesystem-oriented base/candidate snapshot transition validation (`validate-eval-transition`), protected authoritative reviewed history, documented evidence and promotion authority, and pull-request-only benchmark-file byte-identity protection. No benchmark records are added or promoted by this milestone.
- Automated workspace unit test suite, integration tests, binary integrity checks, source registry verification, and CI pipeline.
- Platform architecture documentation, binary pack specification, governance rules, code of conduct, and privacy policies.
